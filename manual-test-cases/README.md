# Manual Test Cases and Templates

Reusable manual testing material: a blank template, plus worked examples that
show how the same structure is filled in for different products.

| File | What it is |
|---|---|
| `QA_Manual_Test_Case_Template.xlsx` | Blank test case template — preconditions, steps, expected results, status, priority, comments. The template to copy for a new suite. |
| `SauceDemo_QA_Test_Cases.docx` | Worked example: a functional suite for [SauceDemo](https://saucedemo.com/), written in English. |
| `FaceBook Log In.xlsx` | Narrow example: login-focused cases for a well-known consumer product. |

## How the template is used

Each case is one row, one behaviour. A test case is only finished when it has
a clear precondition, numbered steps someone else can follow without asking a
question, and one explicit expected result per step. Status and priority are
columns rather than prose so a run can be summarised at a glance.
